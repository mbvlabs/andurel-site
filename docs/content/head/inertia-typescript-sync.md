# TypeScript Sync

Inertia projects keep Go routes and controller payloads as the source of truth. `andurel sync` writes matching TypeScript helpers without creating application-owned Go files.

## Routes

```bash
andurel inspect routes --json
andurel sync routes
andurel sync routes --json
```

`sync routes` writes `resources/js/routes.ts` from the route manifest. Mark routes that should appear in the TypeScript helpers with `routing.InertiaRoute()` when declaring them.

Sample `--json` envelope:

```json
{
  "ok": true,
  "data": {
    "generated_file": "resources/js/routes.ts",
    "generated_helpers": 13,
    "skipped_count": 4,
    "skipped": [
      {
        "variable": "ViteBuild",
        "reason": "route path is not a static string expression"
      }
    ]
  },
  "summary": "Generated 13 route helpers to resources/js/routes.ts (4 skipped)"
}
```

Generated helper shape:

```ts
// Code generated by andurel; DO NOT EDIT.

export const routes = {
  projectCreate: () => '/projects',
  projectDestroy: (id: string) => `/projects/${id}`,
  projectEdit: (id: string) => `/projects/${id}/edit`,
  projectIndex: () => '/projects',
  projectNew: () => '/projects/new',
  projectShow: (id: string) => `/projects/${id}`,
  projectUpdate: (id: string) => `/projects/${id}`,
  sessionNew: () => '/users/sign-in',
}
```

Import helpers via `@/routes` in pages and layouts:

```ts
import { routes } from "@/routes"
import { router } from "@inertiajs/vue3"

router.visit(routes.projectShow(product.id))
```

## Payloads

```bash
andurel sync payloads
andurel sync payloads --json
```

`sync payloads` writes TypeScript types for controller payload / bind structs under `resources/js/types/payloads.ts`.

```json
{
  "ok": true,
  "data": {
    "generated_file": "resources/js/types/payloads.ts",
    "type_count": 5,
    "skipped_count": 0
  },
  "summary": "Generated 5 payload types to resources/js/types/payloads.ts"
}
```

Snippet of generated types:

```ts
// Code generated by andurel; DO NOT EDIT.

export type ProjectData = {
  id: string
  title: string
  status: string
  createdAt: string | null
  updatedAt: string | null
}

export type ProjectIndexProps = {
  items: ProjectData[]
}

export type CreateProjectFormPayload = {
  title: string
  status: string
}
```

Keep JSON tags stable and avoid serializing database rows directly. See [Props](/docs/head/inertia-props).

## Related commands

Scaffolding pages and controllers remains under [Generators](/docs/head/inertia-generators) and [generate](/docs/head/generate). Use [sync](/docs/head/sync) for the full derived-artifact surface (`views`, `queries`, `email`, factories).
